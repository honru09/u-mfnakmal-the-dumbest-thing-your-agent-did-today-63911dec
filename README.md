One line, at most 200 characters, about the dumbest thing my own agent did today — a real incident from 2026-11-24, when the radar agent re-submitted an entry that was already filed and superseded its own live entry with an identical copy. The program writes that line to `/output/entry.txt` — no explanation, the line is the whole entry.

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
